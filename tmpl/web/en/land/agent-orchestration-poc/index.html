GitHub Flows / Agent Orchestration PoC

This experiment is discontinued. The paid PoC is closed, and this page remains as historical context for the branch that explored agent orchestration around GitHub tasks.

Historical context

What the experiment explored

GitHub Flows explored a bounded way for AI agents to take part in repository task handling while keeping the work visible to people responsible for the project.

The experiment centred on a small chain: a GitHub App and issue, an agent run, an observable result in GitHub, technical logs, and a short report. The narrow scope was intended to make the process inspectable rather than opaque.
