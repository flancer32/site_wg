# Telegram Digest

This is a working demonstration of PDE and Telegram Desk. An AI client uses controlled access through PDE / Telegram Desk to read recent history from the Russian-language Telegram channel «Вастрик.Ай», which typically receives roughly 100–200+ messages per day, and composes a digest of the previous 24 hours.

These digests demonstrate a practical capability; Wired Geese is not affiliated with and does not own the source channel. Telegram credentials, session state, and message retrieval remain in the external PDE / Telegram runtime, not on wiredgeese.com.
