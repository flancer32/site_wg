# TeqCMS: Server-side CMS with Nunjucks Templates

<zoom-img
            src="/img/brand/teqfw.webp"
            alt="TeqCMS CMS based on Nunjucks"
            style="max-width: 100%; float: left; margin: 15px 15px 0 0;"
    ></zoom-img>

A package set for creating a CMS with server-side page generation using
        [Nunjucks](https://mozilla.github.io/nunjucks/) templates has been released. The new system is built on the
        **TeqFW** architecture and includes modules for web server, template rendering, and content management:

- [@teqfw/web](https://github.com/teqfw/web) —
            modular web server with HTTP/2 support

- [@flancer32/teq-tmpl](https://github.com/flancer32/teq-tmpl) —
            universal renderer for Nunjucks and Mustache

- [@flancer32/teq-cms](https://github.com/flancer32/teq-cms) —
            file-oriented CMS with localization support

- [@flancer32/teq-cms-demo](https://github.com/flancer32/teq-cms-demo)
            — demo website

All packages use `@teqfw/di` for dependency injection, are designed as plugins, and can be easily combined. The demo shows how to create a multilingual website without a database with full SSR.

The system is adapted for static hosting, automatic translation, and full operation without bundlers or third-party trackers.

Working example: [cms.teqfw.com](https://cms.teqfw.com/ru/)
