# Spanish version of the site: AI translation for $0.05

<zoom-img
            src="/img/blog/2025/07/03-01-deepseek-report.png"
            alt="DeepSeek API usage chart"
            width="100px"
            style="float: left; margin: 15px 15px 0 0;"
    ></zoom-img>

The site **has been translated into Spanish** using the [DeepSeek](https://deepseek.com/) platform and
        capabilities of [TeqCMS](https://cms.teqfw.com/).

It required **42 requests** and **~87,000 tokens** — costing **only $0.05**. The translation was performed automatically based on the original Russian-language files.

Thus, TeqCMS has demonstrated its key feature — **AI localization** of content with
        minimal costs and full control via Git.

All pages, including `/about.html`, `/projects.html` and `/blog/`, are now
        available in [Spanish](/es/). The language can be switched via UI.
