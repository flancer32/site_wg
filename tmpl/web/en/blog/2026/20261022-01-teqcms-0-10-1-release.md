# TeqCMS v0.10.1: better social previews

TeqCMS v0.10.1 was released on October 22, 2026. It improves social previews for publication URLs without a format suffix, including the home page.

When a recognized social crawler such as TelegramBot or Twitterbot sends an ambiguous `Accept` header, the CMS serves server-rendered HTML. Explicit format suffixes and `Accept` preferences still take precedence; AI and command-line clients retain Markdown-oriented behavior.

The host site remains responsible for its social metadata and preview image. Social platform caches may delay visible changes.

TeqCMS publishes version-controlled Markdown and can render HTML for people while making Markdown available to agents. This release helps the same link work in more contexts without maintaining separate content.

The [release notes](https://github.com/flancer32/teq-cms/releases/tag/v0.10.1) report 60 unit tests and 22 acceptance tests, plus type and ESM validation. These are release results, not proof of every host site's configuration.

*This Journal entry records the release date; it was written after the release.*
