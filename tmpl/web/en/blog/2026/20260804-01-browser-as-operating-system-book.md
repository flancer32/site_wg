# My Russian-language book about the browser is now published

<zoom-img src="/img/blog/2026/20260804-01-browser-as-operating-system-book.webp"
        alt="Cover of the book Browser as an Operating System for Developing Modern Applications" width="240px"></zoom-img>

My Russian-language book,
        [“Browser as an Operating System for Developing Modern Applications”](https://bhv.ru/product/brauzer-kak-operatsionnaya-sistema-dlya-razrabotki-sovremennyh-prilozhenij/),
        has been published by BHV.

It presents the browser as a personal operating environment for the internet: a place where web applications
        execute, persist state, use the network, operate within trust boundaries, and connect with a person's digital
        presence. The book is currently available in Russian.

The book approaches the browser through environment, structure, operation, and everyday digital presence.
