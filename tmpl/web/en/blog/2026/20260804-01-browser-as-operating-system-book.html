My Russian-language book about the browser is now published

August 4, 2026

My Russian-language book, “Browser as an Operating System for Developing Modern Applications”, has been published by BHV.

It presents the browser as a personal operating environment for the internet: a place where web applications execute, persist state, use the network, operate within trust boundaries, and connect with a person's digital presence. The book is currently available in Russian.

The book approaches the browser through environment, structure, operation, and everyday digital presence.
