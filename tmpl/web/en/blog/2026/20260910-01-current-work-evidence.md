# Current Work now connects status and Journal evidence

I repurposed the retained Projects page as Current Work. It now separates active systems and directions from the previous and historical work that remains reachable below it.

The page gives Alarisa, PDE, Telegram Desk, Shared Files Desk, and TeqCMS explicit current-state descriptions. The change documents the public representation of these objects; it does not claim that their technical maturity or commercial validation changed today.

Journal Events can carry small authored relationships to Current Work when an Event materially concerns that object. An Event records what changed at a date, while the current-state destination remains responsible for what is accepted now. Existing TeqCMS Events form the first cumulative thread; this site-publication Event does not manufacture evidence for the systems it describes.
