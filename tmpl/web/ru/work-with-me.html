Хорошее совпадение

Приносите задачи, требующие инженерного суждения.

  • web-продукт с неясной или хрупкой архитектурой;
  • конкретная система, которой нужен ответственный разработчик;
  • унаследованный код, который стало трудно изменять;
  • внедрение агентов без долговечного контекста и проверок;
  • прототип, который должен стать надёжной основой продукта.

Скорее не подойдёт

Я не продаю безликое производство кода.

  • массовая сборка страниц без инженерной задачи;
  • анонимный аутстаффинг без влияния на решения;
  • обещания полностью автономной разработки;
  • выбор исполнителя только по минимальной ставке.

02

Спроектировать и сделать

Разработка или спасение системы

Для web-приложения, интеграции, внутреннего инструмента, прототипа или сложной подсистемы, которой нужна личная ответственность опытного инженера. Работаю с браузером, Node.js, данными, внешними API и Linux-развёртыванием.

03

Увеличить инженерные возможности

Система агентской разработки

Для продукта или команды, которым недостаточно случайных чатов с кодирующими агентами. Я создаю долговечный контекст и механизмы контроля, позволяющие агентам последовательно помогать в развитии продукта.

Возможный состав

  • когнитивный контекст от продукта до кода по ADSM;
  • правила репозитория и границы полномочий;
  • документация пакетов и архитектуры для агентов;
  • проверки, тесты и контрольные точки ревью;
  • ограниченные событийные процессы, включая GitHub при необходимости;
  • передача системы, понятной вашей команде.

Как идёт работа

Напрямую, явно и с опорой на доказательства.

  1. ФормулировкаОпределяем дорогую проблему, результат, ограничения и полномочия.
  2. МодельЯ фиксирую продуктовые и архитектурные решения для выполнения.
  3. РеализацияСам создаю решение и делегирую агентам только ограниченные задачи.
  4. ПроверкаТесты, наблюдаемое поведение и ревью заменяют уверенные догадки.
  5. ПередачаВы получаете работающую систему и долговечный контекст.
