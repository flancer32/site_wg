Personal Digital Embassy (PDE)

PDE — персональная инфраструктура, через которую совместимые агенты получают контролируемый доступ к выбранным сервисам и ресурсам. Одна инсталляция представляет одного человека, который управляет границей доступа. PDE практична сама по себе и входит в более широкое направление Alarisa.

Runtime PDE администрирует доступ и отзывное делегирование. Desks добавляют по одному цельному сервису. MCP — технический интерфейс для совместимых агентов, а не продаваемый продукт.

Возможны установка на вашем VPS, управляемая установка, ранний доступ и настройка подходящего Desk. Развёртывание, поддержка и цена согласуются напрямую.

TG-WA Blog Post

Дата начала: февраль 2026

Описание: Консольное приложение на Node.js, созданное за один день в сотрудничестве с агентом Codex по методологии ADSM (Agent-Driven Software Management). После запуска приложение получает последний пост из русскоязычного Telegram-канала, переводит его на английский и испанский языки и автоматически публикует переводы в соответствующие каналы. Проект реализован как практическая проверка разбиения когнитивного контекста ADSM на 7 типовых уровней документации и управления разработкой.

Уровни ADSM в проекте:

  • AGENTS — правила работы с агентом и требования к формализации знаний
  • Constraints — жёсткие рамки и запреты, ограничивающие пространство решений
  • Product — назначение системы и предметные инварианты
  • Architecture — агрегаты, границы и внешние интерфейсы
  • Composition — модель выполнения: run-cycle, фазы и точки завершения
  • Environment — условия исполнения и инфраструктурные ограничения
  • Code — контракты, DI, тестирование и обработка ошибок

Telegram-каналы:

  • alexgusev_lab_ru
  • alexgusev_lab_en
  • alexgusev_lab_es

Репозиторий: GitHub

Mindstream

Дата начала: февраль 2026

Описание: Экспериментальное веб-приложение для наблюдения персонального внимания через векторные представления и эмбеддинги. Приложение читает RSS Хабра, формирует аннотации и обзоры при помощи LLM и рассчитывает маркеры семантической близости публикаций к персональному вектору интересов пользователя. По умолчанию все вычисления выполняются локально в браузере. Проект создан в агентном режиме (LLM + Codex) в рамках методологии ADSM.

Особенности:

  • Персональный вектор интересов формируется в браузере пользователя
  • Эмбеддинги и расчёт семантической близости публикаций
  • Локальный режим по умолчанию без передачи данных на сервер
  • Опциональная анонимная identity (UUID) для дублирования сигналов внимания
  • Клиент-серверная архитектура на базе TeqFW и @teqfw/di
  • Разработка в агентном режиме с использованием LLM и Codex

Live demo: mindstream.app.wiredgeese.com

Репозиторий: GitHub

smtp-logger

Дата начала: апрель 2025

Описание: Утилита на Node.js для логирования исходящих писем в SQL-базу данных (PostgreSQL, MySQL, SQLite). Используется как `pipe`-обработчик в Postfix (`always_bcc` или `aliases`) и регистрирует полные MIME-сообщения. Основана на DI-архитектуре TeqFW, легко встраивается и расширяется.

Особенности:

  • Приём писем из stdin, полная парсинг заголовков и тела
  • Логирование в БД через Knex.js (поддержка PostgreSQL, SQLite, MySQL)
  • Модульная архитектура с @teqfw/di и конфигурацией через CLI
  • Инициализация схемы БД из коробки, конфиги через `.env`
  • Полезен для продакшн и staging-сред — простое аудирование писем

Репозиторий: GitHub

PWA Wallet

Дата начала: июль 2024

Описание: Прогрессивное веб-приложение для хранения, отображения и организации QR- и штрихкодов на мобильных устройствах. Все данные сохраняются локально в браузере и доступны офлайн. Приложение демонстрирует возможности современных PWA: установка, автономная работа, интеграция с аппаратными API и локальными базами. Проект задуман как MVP, но реализует полноценную архитектуру с разделением логики, маршрутов и хранилищ.

Особенности:

  • Сканирование кодов через Camera API с помощью html5-qrcode
  • Отображение штрихкодов с помощью bwip-js
  • Геотрекинг использования карточек с помощью Geolocation API
  • Хранение всех данных в IndexedDB, конфигураций — в localStorage
  • Полная офлайн-работа благодаря Service Worker и Cache API
  • Маршрутная архитектура: отдельные страницы для добавления, просмотра, настройки и использования карточек
  • Фреймворк: Vue 3 + Quasar + @teqfw/di; без сборщиков, установка через npm

Сайт: wallet.wiredgeese.com

Репозиторий: GitHub

Remote Console

Дата начала: июнь 2023

Описание: Утилита для удалённого мониторинга логов JavaScript-приложений в реальном времени. Сообщения из браузера передаются на сервер с помощью Beacon API, а затем ретранслируются всем подключённым разработчикам через SSE (Server-Sent Events). Решение минимально-инвазивное и удобно для локальной разработки и отладки на мобильных устройствах.

Особенности:

  • Отправка логов с клиента через Beacon API или Fetch
  • Реалтайм-трансляция на фронтенд через SSE
  • Поддержка именованных каналов логирования
  • Без авторизации, с публичным тестовым сервером
  • Развёртывание через Node.js и npm без внешних зависимостей

Публичный сервер: console.wiredgeese.com

Репозиторий: GitHub
