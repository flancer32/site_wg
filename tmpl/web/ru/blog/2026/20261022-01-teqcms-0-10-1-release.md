# TeqCMS v0.10.1: превью для социальных сетей

TeqCMS v0.10.1 выпущена 22 октября 2026 года. Она улучшает превью ссылок для социальных сетей для адресов публикаций без суффикса формата, включая главную страницу.

Если распознанный социальный краулер, например TelegramBot или Twitterbot, отправляет неоднозначный заголовок `Accept`, CMS отдаёт HTML, сформированный на сервере. Явный суффикс формата и предпочтения в `Accept` по-прежнему имеют приоритет; ИИ и клиенты командной строки сохраняют поведение, ориентированное на Markdown.

За социальные метаданные и изображение превью отвечает сам сайт. Кэши платформ могут задерживать появление изменений.

TeqCMS публикует Markdown с контролем версий и может формировать HTML для людей, сохраняя доступность Markdown для агентов. Этот выпуск помогает одной и той же ссылке работать в разных контекстах без необходимости поддерживать отдельный контент.

В [примечаниях к выпуску](https://github.com/flancer32/teq-cms/releases/tag/v0.10.1) указаны 60 модульных и 22 приёмочных теста, а также проверка типов и валидация ESM. Это результаты релиза, а не подтверждение правильной настройки каждого сайта.
