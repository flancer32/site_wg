# Разговоры ничего не стоят. Код тоже

<zoom-img src="/img/blog/2026/20260416-01-cost-of-ai-code.png" alt="Стоимость кода, созданного ИИ-агентом"
        width="100px"></zoom-img>

На практическом примере был проведён эксперимент по ADSM: сначала собрано приложение для
        формирования Spotify-плейлиста примерно из ста песен, затем код и тесты удалили и
        приложение дважды заново сгенерировали только по когнитивному контексту. Эксперимент
        показал, что контекст удерживает поведение проекта даже после полного удаления реализации.

После этого была опубликована [статья на Хабре](https://habr.com/ru/articles/1023900/).
        Её копия размещена в [библиотеке сайта](/ru/library/adsm/20260415-01-conversations-code-cost.html).
        Короткий итог: контекст важнее кода, а код можно повторно сгенерировать.
