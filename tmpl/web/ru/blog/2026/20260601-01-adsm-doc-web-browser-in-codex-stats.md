# В аналитике Codex начала собираться статистика по локальному скиллу

<zoom-img src="/img/blog/2026/20260601-01-agent-skill-stats.jpg"
        alt="Статистика по скиллу adsm-doc-web-browser в Codex" width="100px"></zoom-img>

Несколько дней назад был собран скилл **adsm-doc-web-browser** для проверки того, как
        агенты используют скиллы при формировании документации в когнитивном контексте проекта. В основу легло
        рабочее представление о структуре типового веб-приложения и о том, как может быть устроено описание
        его браузерной части.

Скилл пока остаётся внутренней рабочей заготовкой. Он используется в собственных экспериментах и
        дорабатывается по мере применения, без отдельной упаковки под универсальный сценарий.

В веб-интерфейсе Codex в секции аналитики появился отчёт по скиллам, и в нём уже виден
        **adsm-doc-web-browser**. За короткий промежуток времени локальный экспериментальный скилл
        перешёл в состояние, когда по нему уже собирается статистика в OpenAI как по отдельному артефакту
        агентной работы.

Практический вывод здесь простой: скиллы очень быстро становятся наблюдаемой частью рабочей среды.
        Расстояние между локальной проверкой гипотезы и её отражением в телеметрии платформы оказалось
        коротким. Для экспериментов со структурой агентных инструкций это полезный сигнал.
