# Опубликована статья о навыках внутри пакетов TeqFW

![Пакет TeqFW передаёт код приложению и навык ИИ-агенту](/img/library/teqfw/20260810-01-teqfw-agent-skills.webp)

В библиотеке появился материал о том, как пакеты [TeqFW](https://teqfw.com/) поставляют инструкции для ИИ-агентов вместе с кодом. Навык описывает границы компонента, его контракты и правила подключения, а его версия совпадает с версией установленной зависимости.

Пакет предоставляет навык, но проект сам решает, подключать ли его к своей агентской среде. Такой порядок сохраняет контроль за владельцем приложения и помогает агенту работать с локальными правилами вместо случайной версии документации из интернета.

Механизм, примеры из платформенных пакетов и рабочая модель Dependency-bound Agent Skills разобраны в статье [«TeqFW: фреймворк, который объясняет себя ИИ-агенту»](/ru/library/teqfw/20260810-01-teqfw-agent-skills.html).
