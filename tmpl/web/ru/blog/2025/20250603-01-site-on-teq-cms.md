# Переход сайта на TeqCMS

<zoom-img
            src="/img/blog/2025/06/03-01.png"
            alt="Переход сайта на TeqCMS"
            width="100px"
            style="float: left; margin: 15px 15px 0 0;"
    ></zoom-img>

Сегодня мой персональный сайт окончательно переведён на TeqCMS — собственную минималистичную CMS,
        разработанную как часть архитектурной платформы TeqFW. Теперь весь сайт работает на единой системе
        шаблонов, локализации и генерации контента, полностью управляемой через Git и SSR.

TeqCMS позволяет хранить контент в файлах, автоматически переводить его с помощью ИИ и публиковать
        в виде статического сайта без зависимости от баз данных или внешних сервисов. Этот переход стал
        логическим шагом в развитии моих инфраструктурных решений.

Теперь сайт стал не только витриной моих проектов, но и демонстрацией возможностей TeqCMS. Я
        планирую делиться деталями реализации, архитектуры и рабочих процессов — как часть открытого
        эксперимента по интеграции ИИ в повседневную разработку.
