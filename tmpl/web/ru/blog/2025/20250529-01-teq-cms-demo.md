# TeqCMS: серверная CMS на шаблонах Nunjucks

<zoom-img
            src="/img/brand/teqfw.webp"
            alt="TeqCMS CMS на базе Nunjucks"
            style="max-width: 100%; float: left; margin: 15px 15px 0 0;"
    ></zoom-img>

Опубликован комплект пакетов для создания CMS с серверной генерацией страниц на шаблонах
        [Nunjucks](https://mozilla.github.io/nunjucks/). Новая система построена по
        архитектуре **TeqFW** и включает модули для веб-сервера, рендеринга шаблонов и управления
        контентом:

- [@teqfw/web](https://github.com/teqfw/web) —
            модульный веб-сервер с поддержкой HTTP/2

- [@flancer32/teq-tmpl](https://github.com/flancer32/teq-tmpl) —
            универсальный рендерер для Nunjucks и Mustache

- [@flancer32/teq-cms](https://github.com/flancer32/teq-cms) —
            файл-ориентированная CMS с поддержкой локализации

- [@flancer32/teq-cms-demo](https://github.com/flancer32/teq-cms-demo)
            — демонстрационный сайт

Все пакеты используют `@teqfw/di` для внедрения зависимостей, оформлены как плагины и легко
        комбинируются. Демонстрация показывает, как создать многоязычный сайт без базы данных с полным SSR.

Система адаптирована для статического хостинга, автоматического перевода и полной работы без сборщиков или
        сторонних трекеров.

Пример работающего сайта: [cms.teqfw.com](https://cms.teqfw.com/ru/)
