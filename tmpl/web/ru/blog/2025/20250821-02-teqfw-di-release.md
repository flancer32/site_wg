# Первая версия @teqfw/di

<zoom-img
            src="/img/brand/teqfw.webp"

            width="100px"
            style="float: left; margin: 15px 15px 0 0;"

Первый коммит для **@teqfw/di** я сделал 18 августа 2019 года. Тогда появилась идея —
        загрузчик для es6-модулей наподобие [requirejs](https://requirejs.org/), работающий и
        в браузере, и в nodejs. За эти годы библиотека несколько раз переписывалась и обкатывалась в разных проектах.

После статьи на [Хабре](https://habr.com/ru/articles/887646/) я понял, что для
        широкого
        использования библиотеки возможность получить сам контейнер как зависимость не должна существовать. Для
        доверенной команды это было удобно, но для открытых проектов слишком рискованно. Вчера я
        перекрыл эту возможность и выпустил первую версию —
        [1.0.1 на npm](https://www.npmjs.com/package/@teqfw/di/v/1.0.1).

Остальные плагины платформы пока ещё остаются на старом контейнере и несовместимы с новой версией. Их придётся
        переписывать. Но главное — базовая библиотека платформы наконец-то вышла из «пелёнок», и я доволен этим шагом.
