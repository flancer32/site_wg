# От машинного кода к документации

<zoom-img
            src="/img/avatar.jpg"
            alt="Алекс Гусев"
            width="100px"
            style="float: left; margin: 15px 15px 0 0;"
    ></zoom-img>

Разработка приложений меняется. Когда-то основную ценность представлял **машинный код** — эпоха
        мейнфреймов и перфокарт. Затем ценностью стали **программы** на языках высокого уровня, которые
        умели генерировать машинный код.

Сегодня, когда в процесс разработки включаются ИИ-агенты, ценность смещается ещё дальше: главным артефактом
        становится **документация и инструкции**, на основе которых создаются программы. Именно они
        определяют, какие задачи решает код и какие возможности получают пользователи.

Мы входим в эпоху, где не код сам по себе, а **контекст и инструкции для его генерации**
        определяют успех разработки.
