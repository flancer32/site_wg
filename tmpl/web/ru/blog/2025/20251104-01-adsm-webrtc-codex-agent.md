# ADSM: видеочат на WebRTC через Codex-агента

<zoom-img src="/img/blog/2025/20251104-01-adsm-webrtc-codex-agent.png"
        alt="ADSM: видеочат на WebRTC через Codex-агента" width="100px"></zoom-img>

Я проверил, насколько управляемым может быть процесс разработки, если строго опираться на ADSM и работать через
        Codex-агента. Я сделал простое PWA-приложение для видеочата на WebRTC, где вся логика связывания, сигнальные
        каналы и структура компонентов создавались агентом по моим текстовым указаниям. Основные трудности возникли не в
        коде, а в необходимости фиксировать каждую деталь архитектуры, потому что агент не использует контекст вне
        текста. Для удержания проекта в рамках пришлось создать объёмную документацию, значительно превосходящую объём
        кода. Эксперимент подтвердил, что модели можно использовать для построения работающих систем, если обеспечить
        стабильный контекст и строгие рамки. Полная статья написана на русском языке и опубликована на Хабре.
