# Генерация клиентской карты в приложении Домотехника

<zoom-img
            src="/img/blog/2025/09/03-01-client-card.png"
            alt="Клиентская карта в приложении Домотехника"
            width="100px"
            style="float: left; margin: 15px 15px 0 0;"
    ></zoom-img>

Сегодня в клиентское приложение для магазина Домотехника в Риге добавил генерацию клиентской карты. Дизайн
        сделал
        ChatGPT, он же помог выбрать библиотеки для рендера изображения (**canvas**) и штрих-кода
        (**bwip-js**), а также подсказал JS-код.

Проект сам по себе уже морально устарел — хотя я писал его всего полгода назад, весной (там до сих пор
        mustache-шаблоны 👻).
        Тем не менее, обновление прошло быстро: около 2 часов 40 минут вместе с переводами на три языка через ИИ.
        Деплой сделал через GitHub Actions.

Дополнительно ушёл примерно час на оформление с логотипом. Визуальная часть всегда требует больше времени, чем
        кодирование.
        Теперь в приложении есть полноценная карта с именем, ID, штрих-кодом и фирменным знаком.
