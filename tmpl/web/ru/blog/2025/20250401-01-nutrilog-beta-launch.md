# Запущена открытая бета NutriLog

<zoom-img
            src="/img/brand/nutrilog.webp"
            alt="NutriLog"
            width="100px"
            style="float: left; margin: 15px 15px 0 0;"
    ></zoom-img>

Рад сообщить о запуске проекта [NutriLog](https://nutrilog.app.wiredgeese.com/) — персонального AI-ассистента для
        отслеживания калорий, анализа питания и работы с целями по весу.

С 1 апреля стартовала **открытая бета**: доступ получили первые **100 пользователей**,
        которым предоставлены **3 месяца бесплатной подписки**. Для привлечения этой аудитории я провёл
        небольшой эксперимент с **Google Ads** — направив ограниченный, но точно таргетированный трафик.

NutriLog построен на базе [TeqFW](https://github.com/teqfw/di) —
        лёгкой модульной платформы на JavaScript, разработанной мной специально для надёжной архитектуры и управляемой
        разработки.

Система объединяет GPT-подобный чат с внешней памятью: у пользователя остаётся свобода диалога, но появляется
        структура — цели, прогресс, визуализация. Если вам интересен самонаправляемый путь контроля питания и веса —
        попробуйте NutriLog. Обратная связь очень приветствуется!
