# Новый проект: GitHub Action для слияния веток с исключением файлов

<zoom-img
            src="/img/blog/2024/12/25-01.png"
            alt="GitHub Action: слияние веток с исключениями"
            width="100px"
            style="float: left; margin: 15px 15px 0 0;"

Завершил проект по созданию **GitHub Action**, который автоматически сливает одну ветку в другую с
        исключением определённых файлов. После этого обновлённая ветка отправляется обратно в репозиторий.

В процессе реализации оказалось, что для безопасной отправки изменений недостаточно *Personal Access Token (PAT)* — потребовалась настройка **SSH-аутентификации** для надёжного взаимодействия с
        репозиторием.
