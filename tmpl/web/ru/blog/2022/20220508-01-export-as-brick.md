# ES6 export как строительный блок

<zoom-img
            src="/img/post/2022050801.webp"
            alt="Иллюстрация к публикации"
            style="max-width: 100%; float: left; margin: 15px 15px 0 0;"

Что такое строительный блок (*brick*) в современных приложениях на ES2015+? Переменная, функция, класс,
        модуль? Мой ответ — `export`. Сегодня мы организуем JavaScript-код в виде модулей ES6 и связываем их
        через `import`:

```js
import {export1, export2} from "module-name";
```

Убеждён: JavaScript нужны пространства имён, как в «серьёзных» языках. Планирую продолжить тему в следующих
        постах.
