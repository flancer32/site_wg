Los agentes hacen trabajo real

Los agentes son participantes identificados en el trabajo.

Defino la intención, la arquitectura, las restricciones, el contexto, la descomposición y los límites de aceptación. Los agentes de IA investigan, analizan, implementan, inspeccionan, prueban, documentan, mantienen y ayudan con migraciones. Es trabajo directo de ingeniería sustancial dentro de un esfuerzo de producto dirigido de forma explícita.

Wired Geese replantea para el trabajo digital la imagen de los Wild Geese contratados: agentes capaces se suman a una tarea autorizada bajo mi dirección. Alex Gusev sigue siendo el creador humano responsable, y F. Lancer, SIA es la entidad jurídica para relaciones comerciales formales.

Contexto duradero

El conocimiento importante del producto se hace explícito.

El significado del producto no debería existir solo en mi memoria, el código fuente, el historial de chats o la ventana temporal de contexto de un agente.

Uso ADSM —Agent-Driven Software Management— para mantener un contexto cognitivo estructurado: propósito del producto, arquitectura, restricciones, decisiones, conocimiento del entorno y expectativas de verificación. Da a personas y agentes una base duradera para el trabajo posterior, la revisión y el cambio.

Arquitectura y verificación

Diseñado para cambiarse, comprobado antes de aceptarse.

Cuando encaja con el producto, uso TeqFW como plataforma de aplicaciones para software web y JavaScript modular. Su estructura modular, inversión de control y enlace tardío hacen práctico sustituir o ampliar partes sin reconstruirlo todo.

Acepto la salida de los agentes mediante un ciclo explícito: intención → trabajo del agente → inspección, pruebas, comprobaciones estáticas o de tipos, comportamiento renderizado y comparación con el contexto → cambio aceptado. La revisión humana sigue formando parte del ciclo.

Mi práctica más amplia cambia a través del mismo trabajo: construir → observar → comprender → documentar → cambiar el enfoque → construir de nuevo. TeqFW, ADSM, la práctica contextual y el flujo de agentes son herramientas que reviso a partir de resultados en sistemas reales, no una receta universal para todos los equipos.
