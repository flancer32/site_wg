TG-WA Blog Post

Una aplicación de línea de comandos en Node.js que traduce la última publicación de un canal de Telegram en ruso y la publica en canales en inglés y español. Creada con Codex mediante ADSM.

alexgusev_lab_ru · alexgusev_lab_en · alexgusev_lab_es · GitHub

Más detalles

Descripción: Aplicación de consola (CLI) en Node.js creada en un solo día en colaboración con el agente Codex siguiendo la metodología ADSM (Agent-Driven Software Management). Tras el arranque, obtiene la última publicación de un canal de Telegram en ruso, la traduce al inglés y al español y publica automáticamente las traducciones en los canales correspondientes. El proyecto valida en la práctica la división del contexto cognitivo de ADSM en siete niveles estándar de documentación y gestión del desarrollo.

Fecha de inicio: febrero de 2026

Niveles de ADSM en el proyecto:

  • AGENTS — reglas de interacción con agentes y requisitos de formalización del conocimiento
  • Constraints — límites y prohibiciones estrictas que acotan el espacio de soluciones
  • Product — propósito del sistema e invariantes del dominio
  • Architecture — agregados, fronteras e interfaces externas
  • Composition — modelo de ejecución: run-cycle, fases y puntos de finalización
  • Environment — condiciones de ejecución y restricciones de infraestructura
  • Code — contratos, DI, pruebas y manejo de errores

Mindstream

Una aplicación web experimental que explora la atención personal comparando publicaciones con el vector de intereses del usuario. Por defecto, los cálculos se realizan localmente en el navegador.

mindstream.app.wiredgeese.com · GitHub

Más detalles

Descripción: Una aplicación web experimental para observar la atención personal mediante representaciones vectoriales y embeddings. La aplicación lee el RSS de Habr, genera anotaciones y resúmenes con LLMs y calcula marcadores de proximidad semántica entre las publicaciones y el vector personal de intereses del usuario. Por defecto, todos los cálculos se realizan localmente en el navegador. El proyecto fue creado en modo agent-driven (LLM + Codex) dentro de la metodología ADSM.

Fecha de inicio: febrero de 2026

Características:

  • Vector personal de intereses formado directamente en el navegador del usuario
  • Embeddings y cálculo de similitud semántica para publicaciones
  • Modo local-first sin envío de datos al servidor por defecto
  • Identidad anónima opcional (UUID) para duplicar señales de atención
  • Arquitectura cliente-servidor basada en TeqFW y @teqfw/di
  • Desarrollo en modo agent-driven con LLM y Codex

Demo en vivo: mindstream.app.wiredgeese.com

Repositorio: GitHub

smtp-logger

Una utilidad en Node.js que registra correos salientes en una base de datos SQL mediante un manejador pipe de Postfix. Su diseño modular utiliza la inyección de dependencias de TeqFW.

GitHub

Más detalles

Descripción: Utilidad en Node.js para registrar correos salientes en una base de datos SQL (PostgreSQL, MySQL, SQLite). Se usa como manejador `pipe` en Postfix (`always_bcc` o `aliases`) y registra mensajes MIME completos. Basada en la arquitectura DI de TeqFW, fácil de integrar y extender.

Fecha de inicio: abril de 2025

Características:

  • Recepción de correos desde stdin, análisis completo de cabeceras y cuerpo
  • Registro en BD mediante Knex.js (soporte para PostgreSQL, SQLite, MySQL)
  • Arquitectura modular con @teqfw/di y configuración CLI
  • Inicialización de esquema BD incluida, configuración mediante `.env`
  • Útil para entornos de producción y staging — auditoría simple de correos

Repositorio: GitHub

PWA Wallet

Una aplicación web progresiva para organizar códigos QR y de barras en dispositivos móviles. Almacena los datos localmente y demuestra el uso sin conexión, el escaneo y el almacenamiento en el navegador.

wallet.wiredgeese.com · GitHub

Más detalles

Descripción: Aplicación web progresiva para almacenar, mostrar y organizar códigos QR y de barras en dispositivos móviles. Todos los datos se guardan localmente en el navegador y están disponibles sin conexión. Demuestra capacidades modernas de PWA: instalación, funcionamiento offline, integración con APIs hardware y bases locales. Concebida como MVP, pero implementa una arquitectura completa con separación de lógica, rutas y almacenamiento.

Fecha de inicio: julio de 2024

Características:

  • Escanear códigos mediante Camera API con html5-qrcode
  • Mostrar códigos de barras con bwip-js
  • Seguimiento geográfico del uso de tarjetas con Geolocation API
  • Almacenamiento en IndexedDB, configuraciones en localStorage
  • Funcionamiento offline completo gracias a Service Worker y Cache API
  • Arquitectura de rutas: páginas separadas para añadir, ver, configurar y usar tarjetas
  • Framework: Vue 3 + Quasar + @teqfw/di; sin bundlers, instalación vía npm

Sitio: wallet.wiredgeese.com

Repositorio: GitHub

Remote Console

Una utilidad para monitorizar remotamente los logs de aplicaciones JavaScript. Los mensajes del navegador llegan en tiempo real a los desarrolladores conectados, lo que facilita el desarrollo y la depuración en dispositivos móviles.

console.wiredgeese.com · GitHub · Leer el caso técnico → · Leer el caso de diseño de monitorización de logs →

Más detalles

Descripción: Utilidad para monitoreo remoto de logs de aplicaciones JavaScript en tiempo real. Los mensajes del navegador se envían al servidor mediante Beacon API y se retransmiten a los desarrolladores conectados mediante SSE (Server-Sent Events). Solución mínimamente invasiva, útil para desarrollo local y depuración en móviles.

Fecha de inicio: junio de 2023

Características:

  • Envío de logs desde cliente mediante Beacon API o Fetch
  • Transmisión en tiempo real al frontend mediante SSE
  • Soporte para canales de logging nombrados
  • Sin autenticación, con servidor de prueba público
  • Despliegue mediante Node.js y npm sin dependencias externas

Servidor público: console.wiredgeese.com

Repositorio: GitHub

BWL (Body Weight Logger)

Una PWA para registrar el peso, utilizada por un pequeño grupo de amigos y familiares. Aplicaba los principios de TeqFW a la interfaz, la lógica del servidor y las operaciones de base de datos.

bwl.wiredgeese.com · GitHub

Más detalles

Descripción: Aplicación PWA para registrar peso en grupos pequeños. Primera implementación de principios arquitectónicos de TeqFW en interfaz de usuario: inyección de dependencias, CLI, trabajo con BD. Utilizada por un círculo limitado de usuarios, principalmente amigos y familiares.

Fecha de inicio: 2021

Características:

  • Basado en TeqFW: DI, estructura, lógica de servidor
  • Adaptación móvil (mobile-first) y acceso offline
  • Trabajo con BD local, autonomía de interfaz

Sitio: bwl.wiredgeese.com

Repositorio: GitHub
