Rehapp

Una plataforma de rehabilitación personalizada con una PWA para pacientes y un portal para especialistas. Combinaba programas de ejercicios configurables, seguimiento del progreso y herramientas de contenido en un producto médico.

Mi trabajo en la plataforma aplicó la arquitectura modular de TeqFW, la lógica de servidor y la integración con LLM.

rehapp.ru

Más detalles

Descripción: Plataforma para rehabilitación personalizada, incluyendo PWA para pacientes y panel web para especialistas. Implementa principios de TeqFW en un producto médico real: arquitectura modular, inyección de dependencias, lógica de servidor, integración con LLM.

Fecha de inicio: abril de 2022

Características:

  • Ejercicios animados con configuración flexible
  • Soporte para más de 50 programas basados en investigación científica
  • Integración con LLM para traducción automática y generación de contenido
  • Panel personal para especialistas con seguimiento de progreso
  • Mecanismos de motivación: bonos, descuentos y entrevistas de desarrollo personalizadas

Sitio: rehapp.ru

Repositorio: privado

Domotehnika QR Intake

Una aplicación de registro orientada a móviles para el programa de fidelidad de una tienda. Los clientes siguen enlaces QR personales para registrarse y recibir ofertas; los datos se almacenan centralmente para marketing y análisis.

Implementé la aplicación TeqFW para el registro mediante QR, la centralización de datos de clientes y las campañas de fidelización.

tc.klientuklubs.lv

Leer el registro en la Bitácora →

Más detalles

Descripción: Aplicación web minimalista para registro de clientes mediante enlaces QR en el programa de fidelidad de la tienda Domotehnika. El visitante escanea un QR en la tienda, accede a la página de registro y obtiene ofertas personalizadas. Los datos se almacenan centralmente para marketing y análisis.

Fecha de inicio: enero de 2025

Características:

  • Registro de cliente mediante enlace QR personal
  • Mínimo de campos, adaptado para móviles
  • Arquitectura autónoma en TeqFW, sin integraciones externas
  • Lógica de servidor para almacenamiento y análisis

Sitio: tc.klientuklubs.lv

Repositorio: privado
