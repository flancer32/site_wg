Colaboración guiada por el producto

Empieza con algo que ya funciona.

  1. Empieza con un productoRevisa los productos actuales e identifica el que puede ser relevante.
  2. Comprueba el encajeCuéntame el resultado o flujo de trabajo que necesitas. Decido si el producto encaja, si una adaptación acotada tiene sentido o si la petición queda fuera de la dirección actual.
  3. Aclara la adaptaciónCuando encaja, hacemos explícitos la integración, los cambios de flujo, el despliegue, el alojamiento o límites de control y la configuración específica del producto.
  4. Acuerda alcance y precioEl alcance y el precio se acuerdan antes de que empiece la configuración o el desarrollo.
  5. Entrega y continuidadSigo implicado directamente y respondiendo por el resultado. El trabajo posterior puede apoyarse en el código, la arquitectura y el contexto cognitivo del producto cuando se acuerde.

Qué puede incluir

Una colaboración de producto acotada.

  • configuración de un producto existente;
  • adaptación para un flujo definido;
  • integración con otro servicio;
  • una ampliación que crece desde la dirección del producto;
  • evolución o soporte posterior del software entregado cuando se acuerde;
  • transferencia de código fuente o contexto relevante cuando se acuerde específicamente.

Un límite claro

No toda petición encaja en un producto.

La personalización puede crecer desde un producto existente o una dirección de producto. No acepto cualquier petición de software sin relación y puedo rechazar trabajo que no encaje con los productos actuales.
