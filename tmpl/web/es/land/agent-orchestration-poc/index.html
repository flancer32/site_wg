GitHub Flows / Agent Orchestration PoC

Este experimento está discontinuado. El PoC de pago está cerrado y esta página se conserva como contexto histórico de la rama que exploró la orquestación de agentes para tareas de GitHub.

Contexto histórico

Qué exploraba el experimento

GitHub Flows exploraba una forma acotada de que los agentes de IA participaran en la gestión de tareas de un repositorio, manteniendo el trabajo visible para quienes responden por el proyecto.

El experimento se centraba en una cadena pequeña: una GitHub App y una issue, una ejecución del agente, un resultado observable en GitHub, registros técnicos y un informe breve. El alcance limitado buscaba que el proceso pudiera inspeccionarse en vez de quedar opaco.
