# Generación de una tarjeta de cliente en la aplicación Domotekhnika

<zoom-img
            src="/img/blog/2025/09/03-01-client-card.png"
            alt="Tarjeta de cliente en la aplicación Domotekhnika"

Hoy añadí la generación de la tarjeta de cliente a la aplicación de la tienda Domotekhnika en Riga. El diseño lo
        hizo ChatGPT; también ayudó a elegir las bibliotecas para renderizar la imagen (**canvas**) y el
        código de barras (**bwip-js**), además de sugerir el código JS.

El proyecto en sí ya está moralmente desfasado —aunque lo escribí hace apenas medio año, en primavera (todavía
        usa plantillas mustache 👻).
        Aun así, la actualización fue rápida: unas 2 horas y 40 minutos junto con las traducciones a tres idiomas mediante IA.
        El despliegue se hizo a través de GitHub Actions.

Además, se fue aproximadamente una hora en el diseño con el logotipo. La parte visual siempre lleva más tiempo
        que programar.
        Ahora la aplicación tiene una tarjeta completa con nombre, ID, código de barras y marca corporativa.
