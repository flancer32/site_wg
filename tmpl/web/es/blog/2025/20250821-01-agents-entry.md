# AGENTS.md como punto de entrada

<zoom-img
            src="/img/avatar.jpg"
            alt="AGENTS.md como punto de entrada"
            width="100px"
            style="float: left; margin: 15px 15px 0 0;"
    ></zoom-img>

Durante mucho tiempo pensé qué archivo usar como punto de entrada para los agentes en mis proyectos. Me decidí por **AGENTS.md**.
        Resultó no solo ser un nombre conveniente, sino un formato establecido, compatible con muchas herramientas y utilizado en miles de repositorios.

En esencia, es un README para agentes: un lugar dedicado para fijar comandos, reglas y especificaciones. Este enfoque aligera la documentación para las personas y ofrece a los agentes una base predecible.
        En ADSM esto es especialmente importante: el contexto se traslada de un proyecto a otro y sigue siendo comprensible.

Más detalles en [agents.md](https://agents.md/).
