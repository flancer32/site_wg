# Ya se ha publicado mi libro en ruso sobre el navegador

<zoom-img src="/img/blog/2026/20260804-01-browser-as-operating-system-book.webp"
        alt="Portada del libro El navegador como sistema operativo para desarrollar aplicaciones modernas" width="240px"></zoom-img>

La editorial BHV ha publicado mi libro en ruso,
        [«El navegador como sistema operativo para desarrollar aplicaciones modernas»](https://bhv.ru/product/brauzer-kak-operatsionnaya-sistema-dlya-razrabotki-sovremennyh-prilozhenij/).

El libro presenta el navegador como un entorno operativo personal para internet: el lugar donde las
        aplicaciones web se ejecutan, conservan su estado, utilizan la red, respetan límites de confianza y se
        conectan con la presencia digital de una persona. Por ahora está disponible en ruso.

El libro aborda el navegador desde el entorno, la estructura, el funcionamiento y la presencia digital cotidiana.
