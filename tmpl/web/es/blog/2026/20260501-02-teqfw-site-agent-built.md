# Actualicé teqfw.com con Codex

<zoom-img src="/img/blog/2026/20260501-02-teqfw-site.png"
        alt="Actualicé teqfw.com con Codex" width="100px"></zoom-img>

Actualicé mi [sitio teqfw.com](https://teqfw.com/), empezando por
        la portada y el material relacionado.

El sitio está construido sobre **TeqFW**. Un agente Codex preparó por completo el código, los
        textos, el diseño y la maquetación de la página.

El trabajo se hizo junto con el agente Codex siguiendo mi metodología ADSM,
        `Agent-Driven Software Management`.

El material de esta actualización se repartió así:

`440 KB` - contexto del proyecto, es decir, documentación;

        `512 KB` - especificaciones de TeqFW y del sitio SSR;

        `77 KB` - código de la aplicación para procesar plantillas con Nunjucks;

        `80 KB` - texto de las plantillas, es decir, maquetación y páginas;

        `160 KB` - estática, incluidas las imágenes.

La conclusión práctica es clara: en este tipo de trabajo, la documentación tiene que superar con margen al
        código. Así el agente dispone de un marco más claro y puede ir construyendo el resultado paso a paso.
