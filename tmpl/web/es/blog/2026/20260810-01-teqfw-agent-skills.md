# Nuevo artículo: Agent Skills dentro de los paquetes de TeqFW

![Un paquete de TeqFW proporciona código a la aplicación y una skill al agente de IA](/img/library/teqfw/20260810-01-teqfw-agent-skills.webp)

La biblioteca incorpora un artículo sobre cómo los paquetes de [TeqFW](https://teqfw.com/) distribuyen instrucciones para agentes de programación junto con el código. Una skill describe los límites del componente, sus contratos y las reglas de integración, y su versión coincide con la versión de la dependencia instalada.

El paquete proporciona la skill y el proyecto decide si la expone a su entorno de agentes. Este orden mantiene el control en manos del propietario de la aplicación y permite que el agente trabaje con reglas locales en vez de una versión cualquiera de la documentación encontrada en Internet.

El mecanismo, los ejemplos de paquetes de la plataforma y el modelo Dependency-bound Agent Skills se explican en [«TeqFW: un framework que sabe explicarse a los agentes de IA»](/es/library/teqfw/20260810-01-teqfw-agent-skills.html).
