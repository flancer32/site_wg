# JavaScript: 3 вида import’ов

Применение оператора `import` для связывания es-модулей зависит от того, для какой среды модуль предназначен. Если коротко, то можно выделить три среды:

*   nodejs
*   браузер
*   service worker

## nodejs

Особенностью этой среды является то, что в коде можно импортировать nodejs-библиотеки и npm-пакеты:

import {join} from 'path'; // node lib

import {computed} from '[@vue/reactivity](http://twitter.com/vue/reactivity)'; // npm package
## Браузер

Импортировать модули в среде браузера можно по абсолютному URL’у с любого сервера, чья политика CORS разрешает это делать:

import fn from '[https://example.com/module.mjs'](https://example.com/module.mjs');
## Относительная адресация

Относительная адресация одинаково работает как в браузере, так и в node (в статическом и динамическом вариантах):

import fn from './path/to/module.mjs'; // staticimport ('./path/to/module.mjs').then((mod) => {...}); // dynamic
## Service worker

На данный момент (2021/10) в среде worker’ов для импорта модулей принято использовать [importScripts](https://developer.mozilla.org/en-US/docs/Web/API/WorkerGlobalScope/importScripts):

importScripts('./path/to/module.mjs');
Обычный `import` уже доступен в Chrome (и других браузерах на движке [Blink](https://ru.wikipedia.org/wiki/Blink_(%D0%B4%D0%B2%D0%B8%D0%B6%D0%BE%D0%BA))) и в [Safari](https://webkit.org/blog/11577/release-notes-for-safari-technology-preview-122/#:~:text=Added%20support%20for%20modules%20in%20Service%20Workers) (движок [WebKit](https://ru.wikipedia.org/wiki/WebKit)). В [Firefox](https://github.com/mozilla/standards-positions/issues/499) (движок [Gecko](https://ru.wikipedia.org/wiki/Gecko)) пока не работает.

Так как `importScripts` ничего не возвращает, то связь между объектами модулей приходится делать через `globals`(контекст worker’а). Т.е., как такового экспорта-импорта в данном случае не происходит, можно представить код в виде единой “_простыни_”, разбитой на отдельные “_кусочки_”, выполняемые последовательно по мере их загрузки через `importScripts`.

Динамический импорт в среде worker’ов [не работает](https://web.dev/es-modules-in-sw/).
