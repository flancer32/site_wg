## Purpose

Defines the provisional productized-engineering offer for controlled MCP access to an existing customer service or API.

## Level Map

- `AGENTS.md` — local offer instructions and map.
- `overview.md` — provisional buyer outcome, boundaries, validation questions, exclusions, and unresolved packaging.

## Level Boundary

Defines:

- The bounded commercial hypothesis for an MCP integration pilot.
- Candidate scope, authority, delivery, verification, and evidence boundaries.
- The questions that paid delivery must answer before standardization.

Does NOT define:

- A universal MCP package, fixed price, delivery time, SLA, or supported-system matrix.
- Technical architecture, protocol implementation, deployment procedure, or code contract.
- Final public copy, route, form, agreement, or enterprise-security claim.
