- Changed: `20260909`

## Purpose

Define the coherent secondary entry point into retained knowledge, history, and proof.

## Route

- `/{locale}/resources/`

## Target Role

Resources organizes links to:

- Project archive;
- Library;
- Journal;
- Books;
- selected technical cases, historical systems, discontinued experiments, and external proof.

It is an index and discovery layer. Existing content stays at its established routes and is not migrated under `/resources/` merely to match the hub.

## Commercial Relationship

Resources supports search acquisition, evidence, intellectual context, technical inspection, and trust. It may expose genuine contextual links back to Products, Alarisa, Technology, About, or Custom Development, but it must not assign commercial status from topical similarity or turn every retained page into a sales page.

## Implementation Boundary

The route is new and belongs to the footer Knowledge group, not primary navigation. Final taxonomy, featured-item logic, filtering, search behavior, and visual composition require later design; an unstructured dump of every URL is not acceptable.
